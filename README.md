# پزشک گوشی — نسخه بازطراحی‌شده (Phone Doctor Rebuild)

بازسازی کامل پروژه اپلیکیشن «پزشک گوشی» نسخه ۱.۰ از روی فایل APK اصلی، با اعمال تغییرات درخواستی.

> برنامه اصلی (ابزار تخصصی تست سلامت سخت‌افزار گوشی با ۳۳ ابزار حرفه‌ای) ساخته توسعه‌دهنده **AbbasTech (سید عباس حسینی سانچارکی)** است و تمامی حقوق اثر متعلق به ایشان می‌باشد. این ریپو صرفاً یک **بیلد تغییر‌یافته** از همان برنامه است.

## 📱 مشخصات خروجی

| مورد | مقدار |
| --- | --- |
| نام پکیج | `com.abbas.drmobile` |
| نام برنامه | پزشک گوشی |
| نسخه | 1.0 (کد 1) |
| حداقل اندروید | 7.0 (API 24) |
| هدف | Android 16 (API 36) |
| فایل خروجی | `apk/پزشک گوشی_1.0_patched.apk` |
| امضا | RSA 2048 — SHA384withRSA (v2 + v3) |

## ✂️ تغییرات اعمال‌شده نسبت به نسخه اصلی

1. **حذف کامل بخش «شبکه‌های اجتماعی و کانال‌ها»** از صفحه «اطلاعات» — شامل کارت‌های کانال تلگرام (AbbasTech10)، یوتیوب و آپارات.
2. **حذف کامل بخش «دربه ما و کپی‌رایت»** — شامل کارت «درباره برنامه و صاحب اثر» و متن‌های سلب مسئولیت/کپی‌رایت.
3. **حذف بخش «شبکه‌های اجتماعی و پیام‌رسان‌ها»** از صفحه پشتیبانی (لینک‌های یوتیوب، تلگرام ×۲، آپارات و روبیکا).
4. عنوان صفحه به «اطلاعات و امکانات» و زیرعنوان آن به «امکانات و خدمات مایکت» تغییر کرد تا اشاره‌ای به بخش‌های حذف‌شده باقی نماند.
5. **حذف کامل درگاه پرداخت (مایکت) برای تست** — همه‌ی ورودی‌های صفحه‌ی «خرید نسخه ویژه» حذف شدند:
   - تب «خرید Pro» از نوار پایین صفحه‌ی اصلی حذف شد (حالا: خانه، گزارش سلامت، اطلاعات).
   - بنر «خرید نسخه ویژه» (`banner_buy_pro`) از صفحه‌ی اصلی حذف شد.
   - کارت بنفش «ارتقا به نسخه حرفه‌ای (Pro)» از صفحه‌ی اطلاعات حذف شد.
   - دکمه‌ی «خرید و فعال‌سازی» داخل دیالوگ «قفل بودن قابلیت‌ها» برداشته شد (دیالوگ و دکمه بستن باقی است).
   - کلیک روی چیپ «خرید Pro» در هدر دراور بدون عمل شد.
6. صفحه‌ی خرید (BuyProScreen) و منطق billing مایکت در کد باقی مانده‌اند اما **از هیچ نقطه‌ای قابل دسترسی نیستند**؛ سایر بخش‌ها (۳۳ ابزار تست، اسکنرها و...) دست‌نخورده‌اند.

فایل‌های پچ‌شده:
- `smali_classes2/com/example/ui/screens/SettingsAndAboutScreenKt.smali`
- `smali_classes2/com/example/ui/screens/SettingsAndSupportScreensKt.smali`
- `smali_classes2/com/example/ui/screens/HomeScreenKt.smali` (تب خرید، بنر و کلیک دراور)
- `smali_classes2/com/example/ui/components/ComponentsKt.smali` (دکمه خرید دیالوگ)

اسکریپت‌ها: `scripts/patch_smali.py` (تغییرات ۱ تا ۴)، `scripts/patch_remove_payment.py` (تغییر ۵)، `scripts/repack_v3.py` (بازساخت APK) و `scripts/audit_deletions.py` (بررسی صحت پچ‌ها).

## 🐞 رفع کرش نسخه قبل (مهم)

نسخه‌ی قبلی این ریپو هنگام باز شدن برنامه کرش می‌کرد. علت: هنگام حذف کدِ تب «خرید Pro» از `HomeScreen`، چند دستور (`move-object`) که مقادیر رجیسترهای `v51` تا `v54` را تعیین می‌کردند هم همراه آن کد حذف شده بودند، در حالی که کدِ باقی‌مانده (تب «اطلاعات») همان رجیسترها را می‌خواند؛ نتیجه‌اش خواندن رجیسترِ مقدار-نشدَه و کرش آنی در شروع برنامه بود.

رفع: چهار دستور بازیابی رجیستر دقیقاً بعد از نقطه‌ی حذف اضافه شد:

```smali
move-object/from16 v51, v37
move-object/from16 v52, v49
move-object/from16 v53, v38
move-object/from16 v54, v50
```

صحت بیلد جدید با روش‌های زیر تأیید شد:
- مقایسه‌ی بایت‌به‌بایت `classes2.dex` جدید با خروجی baksmali (فقط همین ۴ دستور تفاوت دارد)
- بررسی کامل ۸۲۰۸ کلاس داخل dex (هیچ کلاسی حذف یا اضافه نشده)
- بررسی liveness همه‌ی رجیسترها در همه‌ی بخش‌های حذف‌شده (`scripts/audit_deletions.py`)
- تأیید امضا (v1+v2+v3)، zipalign و تراز بودن `resources.arsc` و فایل‌های `lib/*.so`

## 📂 ساختار ریپو

```
├── apk/                        ← فایل APK نهایی آماده نصب (امضاشده)
├── apktool-project/            ← سورس کامل دیکامپایل‌شده (پروژه apktool، پچ‌شده)
│   ├── AndroidManifest.xml
│   ├── apktool.yml
│   ├── res/                    ← منابع (آیکون‌ها، استرینگ‌ها، ...)
│   ├── assets/
│   ├── lib/                    ← کتابخانه‌های native (۴ معماری)
│   └── smali*/                 ← کد برنامه (۴ فایل dex به‌صورت smali)
├── keystore/drmobile.keystore  ← کلید امضای این بیلد
├── scripts/patch_smali.py      ← اسکریپت اعمال تغییرات روی سورس smali
└── README.md
```

## 🔧 نحوه ساخت مجدد APK از سورس

```bash
# ۱) بیلد با apktool (نسخه 2.9 به بالا)
apktool b apktool-project -o drmobile-unsigned.apk

# ۲) امضا (ابزار uber-apk-signer یا apkspector)
java -jar uber-apk-signer.jar -a drmobile-unsigned.apk \
     --ks keystore/drmobile.keystore \
     --ksAlias drmobile \
     --ksPass drmobile2026 --ksKeyPass drmobile2026
```

### مشخصات Keystore

| مورد | مقدار |
| --- | --- |
| فایل | `keystore/drmobile.keystore` |
| Alias | `drmobile` |
| Store password | `drmobile2026` |
| Key password | `drmobile2026` |
| الگوریتم | RSA 2048، اعتبار ۳۰ سال |

> ⚠️ اگر می‌خواهید آپدیت‌های بعدی را خودتان منتشر کنید، این keystore را در جای امن نگه دارید؛ نصب نسخه جدید فقط با همین امضا روی نسخه فعلی ممکن است.

## 🛠 اعمال مجدد تغییرات

اگر سورس را دوباره از APK اصلی دیکامپایل کردید، می‌توانید تغییرات را با اسکریپت موجود اعمال کنید:

```bash
apktool d پزشک-گوشی_1.0.apk -o full_decoded
python3 scripts/patch_smali.py
apktool b full_decoded -o patched.apk
```

## 📲 نصب

فایل `apk/پزشک گوشی_1.0_patched.apk` را دانلود و نصب کنید. چون امضای این بیلد با نسخه مایکت متفاوت است، ابتدا نسخه قبلی را حذف (Uninstall) کنید.
